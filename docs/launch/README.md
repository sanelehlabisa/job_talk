# Job Talk launch copy

## LinkedIn project entry

**Project name:** Job Talk — conversational job applications

**Link:** https://jobtalk.roventics.com

I built Job Talk to test a simpler hiring process. Recruiters describe a role,
candidates apply through chat without creating an account, and recruiters compare
structured evidence against the same job requirements.

Built with React, FastAPI, PostgreSQL and Gemini, deployed with Docker and Nginx.
Free early beta. I’m looking for recruiters and job seekers to try it and share
honest feedback. Recruiter access is manually approved.

## LinkedIn post

Can a conversation make job applications easier to complete and compare?

I built Job Talk to test that idea. Candidates apply through chat, and recruiters
review their answers against a shared set of job requirements.

It’s live, free, and still an early beta. I’m looking for a few recruiters and job
seekers to test one role and tell me what helps, what’s confusing, and what breaks.

Try it: https://jobtalk.roventics.com

Recruiters: request access with your email and I’ll review it. Candidates don’t
need an account. Feedback here or by DM is welcome.
